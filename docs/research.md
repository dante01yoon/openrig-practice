- 작성: team-research@culture
- 기준 데이터: `data/events.json` (293건, 수정 시각 2026-10-31 20:05 기준 파일)
- 기준일: 2026-10-31 (날짜 판별의 "오늘")
- 재현: 아래 명령은 저장소 루트에서 실행. 파일은 읽기만 함.

표기: **[사실]** 데이터에서 직접 확인 / **[추정]** 값으로 미루어 본 해석 / **[불확실]** 확인 못 한 것

## 요약 (lead 권고 3~5줄)

1. 무료 여부는 `IS_FREE`("무료" 211 / "유료" 82)를 기준으로 삼는다. `USE_FEE`가 빈 행 157건은 모두 `IS_FREE="무료"`이고, 무료 문구·0원·없음 등 `USE_FEE`와 대체로 맞는다.
2. `IS_FREE`와 `USE_FEE`가 어긋나는 행은 7건이다. 명백한 충돌은 1건(삼청각 30,000원인데 무료)뿐이고, 나머지는 "무료 공연 + 별도 입장료·예약금"처럼 해석이 갈린다. 카드에 "요금 확인" 표시를 붙이는 것을 권한다.
3. 구(`GUNAME`)는 서울 25개 구 이름만 있고 표기 흔들림이 없다. 필터 값은 이 25개를 그대로 쓰면 된다.
4. 날짜는 형식이 모두 같고 시작>종료인 행이 없다. 다만 종료일이 `2626-08-08`인 행 1건이 있어 날짜 필터에서 제외하거나 별도 표시가 필요하다.
5. 제목이 같은 행 2건(`[종로문화재단] 2026 종로 가족공연축제`)은 서로 다른 등록 건이다. 중복 제거는 제목이 아니라 `HMPG_ADDR`의 `cultcode`로 해야 한다.

## 2. 구 (GUNAME)

- 값 25종. 서울 자치구 25개가 모두 나오고, 서울 외 값과 표기 흔들림(공백·약칭 등)은 없다 [사실].

- **[추정]** `GUNAME`은 행사 장소의 구가 아니라 등록된 대표 구일 수 있다. 확인 예: "국제 프리스타일 축구 월드 챔피언쉽"은 `GUNAME="강남구"`인데 1–2일차 장소(`PLACE`)는 신도림 오페라 하우스(구로구)다. 한 건만 본 것이므로 전수 검증은 하지 않았다 [불확실].
- 권고: 필터 라벨은 `GUNAME` 그대로 쓰되, "장소의 구"처럼 보이게 쓰지 않는다.

## 3. 날짜

- 형식 [사실]
  - `DATE`: 모든 행이 `YYYY-MM-DD~YYYY-MM-DD`
  - `STRTDATE`, `END_DATE`: 모든 행이 `YYYY-MM-DD 00:00:00.0`
  - `DATE`의 두 날짜는 `STRTDATE`, `END_DATE`의 날짜 부분과 293건 모두 일치한다.
- 시각 부분은 전부 `00:00:00.0`이다. 시각 처리는 필요 없다 [사실].
- 시작>종료인 행: 0건 [사실].
- 시작 연도: 전부 2026 [사실].
- 종료 연도 분포 [사실]: 2026 265, 2027 26, 2029 1, **2626 1**.
- **이상치 (2626)**: `[서울영화센터] 스마트폰으로 만드는 나만의 영화 - Ⅱ.프리프로덕션`, `DATE="2026-07-18~2626-08-08"`, `END_DATE="2626-08-08 00:00:00.0"`. 원자료 오기로 보인다 [추정].
  - 오기가 `2026-08-08`이라면 2026-10-31 이전에 끝난 행사가 되어 README의 "11월 이후 끝나는 행사 293건"과 맞지 않는다. 따라서 어느 쪽인지 데이터만으로는 정할 수 없다 [불확실].
  - 현재 값을 그대로 쓰면 이 행사는 2026-07-18 이후 모든 날짜에 "열리는 행사"가 되어 날짜 필터를 왜곡한다.
  - 권고: 날짜 필터 결과에서 제외하고 "종료일 확인 필요"로 표시하거나, 날짜 기반 필터를 쓰지 않는 목록에만 둔다.
- 기준일(2026-10-31) 기준 [사실]: 이미 끝난 행 0건, 아직 시작 안 한 행 123건(나머지 170건은 진행 중). 2626 행은 진행 중으로 계산됨.
- 경계 판별 [추정, 권고]: "날짜 D에 열리는 행사"는 `STRTDATE_date <= D <= END_DATE_date` (당일 포함)로 본다. 시각 부분이 없으므로 `"YYYY-MM-DD"` 문자열 앞 10자리를 잘라 비교하는 것이 안전하다. `new Date("2026-11-01 00:00:00.0")`처럼 파싱하면 공백 형식이 브라우저마다 달라질 수 있다.

## 4. 무료 판별

### 4-1. 기본 분포 [사실]

| IS_FREE | USE_FEE 빈 값 | USE_FEE에 "무료" 문구 | USE_FEE 기타 | 합계 |
|---|---|---|---|---|
| 무료 (211) | 157 | 47 | 7 | 211 |
| 유료 (82) | 0 | 1 | 81 | 82 |

- `USE_FEE`가 빈 행은 모두 무료. 무료 행에 빈 `USE_FEE`가 많은 것은 원자료가 무료 행의 요금을 비워 두는 방식 때문으로 보인다 [추정].
- `IS_FREE="무료"`인 행 중 `USE_FEE`에 "무료" 문구가 없는 7건은 `0`, `0원`, `없음`, `없음(전액지원)`, `프로그램별 상이` 등이다. 무료로 봐도 무방하거나 판단이 애매하다 [사실·추정].

### 4-2. 어긋나는 행 [사실]

| 구분 | 행사 (제목 일부) | IS_FREE | USE_FEE | 권고 표시 |
|---|---|---|---|---|
| 명백한 충돌 | 2026 삼청각 명상 문화강좌 [마음을, 걷다] | 무료 | 30,000원 | 요금 확인 |
| 무료 + 별도 비용 | [서울상상나라] 그림책 작업실 / 양육자 대상 육아동지 캠페인 / 사랑하는 사이 (3건) | 무료 | 무료(입장료 4,000원 별도) | 무료 + 입장료 별도 |
| 무료 + 예약금 | 연극 [점프x컷] | 무료 | 무료공연이나 1인 10,000원 예약금(환불) | 무료 + 예약금 |
| 유료 + 일부 무료 | 국제 프리스타일 축구 월드 챔피언쉽 [2026 KILL THAT BALL: SEOUL] | 유료 | 참가비 30,000원 / 관람 1–2일차 무료, 3일차 10,000원 | 요금 확인 |
| 무료 + 요금 상이 | [송파 청년아티스트센터] 예술가와 함께하는 풍납 탐구 생활 11월 프로그램 | 무료 | 프로그램별 상이 | 요금 확인 |

- 합계 7건. 명백한 충돌은 1건이다 [사실].
- 권고 기준 [추정]:
  1. 무료 여부 판별은 `IS_FREE === "무료"`로 한다. 원자료의 공식 판별 필드이고, 대부분의 `USE_FEE`와 맞는다.
  2. "무료" 필터 결과에 위 7건 중 `USE_FEE`에 금액 또는 "요금 확인" 성격의 문구가 있는 행은 카드에 "요금 확인" 배지를 붙인다. 판별 규칙을 바꾸지는 않는다.
  3. `USE_FEE`를 정규식으로 파싱해 무료를 다시 판정하는 방식은 권하지 않는다. "무료 공연이나 예약금 있음" 같은 문장을 잘못 판정하기 쉽다.
- 공식 필드 설명은 확인하지 못했다 (아래 5장). `IS_FREE`의 공식 정의는 [불확실].

## 8. 재현 명령

```bash
# 행 수, 구 목록
node -e 'const r=JSON.parse(require("fs").readFileSync("data/events.json","utf8")); console.log(r.length, [...new Set(r.map(x=>x.GUNAME))].length)'

# IS_FREE × USE_FEE 빈 값
node -e 'const r=JSON.parse(require("fs").readFileSync("data/events.json","utf8")); const c={}; r.forEach(x=>{const k=x.IS_FREE+"|"+(String(x.USE_FEE).trim()?"값있음":"빈값"); c[k]=(c[k]||0)+1}); console.log(c)'

# 종료 연도 분포 (2626 확인)
node -e 'const r=JSON.parse(require("fs").readFileSync("data/events.json","utf8")); const c={}; r.forEach(x=>{const y=x.END_DATE.slice(0,4); c[y]=(c[y]||0)+1}); console.log(c)'

# 시작>종료 행 수 (0이어야 함)
node -e 'const r=JSON.parse(require("fs").readFileSync("data/events.json","utf8")); console.log(r.filter(x=>x.STRTDATE.slice(0,10)>x.END_DATE.slice(0,10)).length)'

# 무료 판별 어긋남 목록
node -e 'const r=JSON.parse(require("fs").readFileSync("data/events.json","utf8")); r.filter(x=>x.IS_FREE==="무료" && String(x.USE_FEE).trim() && !/무료/.test(x.USE_FEE)).forEach(x=>console.log(x.TITLE, "|", x.USE_FEE))'
```
