# 화면 설계: 서울 문화행사 찾기 (필터 + 행사 카드)

작성: lead · 2026-11-01 · 상태: 확정(docs/research.md 반영)

## 목표와 완료 조건

사용자가 구·날짜·무료 여부로 행사를 좁혀 보고, 각 행사를 카드로 훑어볼 수 있다.

완료 조건
- 세 필터가 AND로 결합되어 즉시 반영되고, 결과 건수가 함께 바뀐다.
- 행사가 카드 격자로 보이고, 카드에서 상세 페이지로 이동할 수 있다.
- 결과 0건, 목록 로드 실패에도 사용자가 다음 행동을 알 수 있다.
- 필터 규칙은 순수 함수로 분리되어 `npm test`(node --test)로 검증된다.
- 375px 폭에서 가로 스크롤 없이 쓸 수 있고, 키보드만으로 모든 컨트롤을 조작할 수 있다.

범위 밖: 서버 API 변경, 정렬 옵션, 지도, 검색어, URL 쿼리 상태 저장, 페이지네이션, 외부 패키지 추가.

## 화면 구성 (위에서 아래로)

```
┌──────────────────────────────────────────────┐
│ 서울 문화행사 찾기                              │  h1
│ 서울 열린데이터광장 문화행사 정보 (2026-10-31)   │  작은 회색 출처 문구
├──────────────────────────────────────────────┤
│ [구 ▾ 전체 (293)] [날짜 □ yyyy-mm-dd] [☐ 무료만] [초기화] │  필터 줄(좁으면 줄바꿈)
│ 행사 211개                                     │  결과 건수 (aria-live=polite)
├──────────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐               │
│ │ 이미지  │ │ 이미지  │ │ 이미지  │   카드 격자    │
│ │무료 전시│ │ ...    │ │ ...    │               │
│ │ 제목    │ │        │ │        │               │
│ │ 기간    │ │        │ │        │               │
│ │ 장소·구 │ │        │ │        │               │
│ │ 요금    │ │        │ │        │               │
│ └────────┘ └────────┘ └────────┘               │
└──────────────────────────────────────────────┘
```

### 필터 줄 (`<form>`, 제출 없음 — 값이 바뀌면 바로 반영)
1. **구** `<select>` 레이블 "구". 첫 항목 "전체 (293)", 이어서 데이터에 있는 구를 가나다순으로 "종로구 (57)"처럼 전체 데이터 기준 건수와 함께. 목록은 데이터에서 만든다(현재 25개 구, 빈 값·표기 흔들림 없음 — research 2장). GUNAME은 등록 구일 수 있으므로 레이블은 "구"로만 쓰고 "장소"라고 부르지 않는다.
2. **날짜** `<input type="date">` 레이블 "이 날짜에 열리는 행사". 비어 있으면 날짜로 거르지 않는다. 값 D가 있으면 `STRTDATE.slice(0,10) <= D <= END_DATE.slice(0,10)`(문자열 비교, 양 끝 포함)인 행사만.
3. **무료만 보기** 체크박스. 켜면 무료 행사만. 판별 규칙은 아래 "무료 판별".
4. **초기화** 버튼(type=button): 세 필터를 기본값으로 되돌리고 목록 전체를 다시 보인다.

필터 줄은 flex-wrap. 375px에서는 각 컨트롤이 한 줄씩 쌓여도 된다.

### 결과 건수
`행사 N개` 문구. `aria-live="polite"`. 필터가 하나라도 걸려 있으면 `행사 N개 (전체 293개 중)`.

### 카드 (`<ul>` 격자 안의 `<li><article>`)
- 격자: `grid-template-columns: repeat(auto-fill, minmax(260px, 1fr))`, 간격 16px. 375px에서는 1열.
- 위에서 아래로:
  - **이미지**: MAIN_IMG, `loading="lazy"`, `alt=""`(제목이 바로 아래 있으므로 장식), 4:3 비율 고정·object-fit cover. 로드 실패나 빈 값이면 같은 크기 회색 칸에 분류명(CODENAME) 텍스트.
  - **배지 줄**: "무료"(초록) 또는 "유료"(회색) 배지 + 분류(CODENAME). 색만으로 구분하지 않고 글자로 표시.
  - **제목**: `<h2>` 안 링크. 링크 대상은 HMPG_ADDR(없으면 ORG_LINK). http/https 링크만 링크로 만들고 아니면 일반 텍스트. 새 탭(`target="_blank" rel="noopener noreferrer"`). 길면 3줄까지.
  - **기간**: `2026-11-01 ~ 2026-12-31` (STRTDATE/END_DATE의 날짜 부분). 하루짜리면 날짜 하나.
  - **장소**: `PLACE · GUNAME`.
  - **요금**: USE_FEE 원문을 자르지 않고 전부(최대 93자). 비어 있으면 무료 행사는 "무료", 유료 행사는 "요금 정보 없음".
  - **대상**: USE_TRGT가 있으면 작게.
- 정렬: 서버가 주는 순서 그대로. 제목이 같은 행(종로 가족공연축제 2건)은 별개 등록이므로 둘 다 보인다(중복 제거 없음).

### 빈 결과
카드 자리에 "조건에 맞는 행사가 없습니다." 문구와 "필터 초기화" 버튼.

### 로드 실패
`/api/events` 실패 시 "행사 목록을 불러오지 못했습니다. 잠시 후 새로고침해 주세요." 필터는 비활성.

## 데이터 규칙 (research 반영 결정)
- **무료 판별**: `IS_FREE === "무료"` 이면 무료, 그 밖은 유료. USE_FEE로 다시 판정하지 않는다(research 4장: 무료 211 / 유료 82).
- **요금 불일치 7건**(예: 무료인데 "30,000원", "입장료 4,000원 별도"): 별도 "요금 확인" 배지는 만들지 않는다. 배지를 붙이려면 USE_FEE를 해석하는 추측 규칙이 필요해서다. 대신 카드에 USE_FEE 원문을 잘림 없이 보여 주어 사용자가 직접 읽게 한다.
- **종료일 2626-08-08 1건**(서울영화센터): 원자료를 고치거나 숨기지 않는다. 카드 기간에 원문 날짜가 그대로 보이므로 사용자가 알아볼 수 있다. 이 때문에 2026-07-18 이후 어느 날짜를 골라도 이 행사가 결과에 끼는 것은 알려진 한계로 보고한다.
- **링크**: http(s)로 시작할 때만 링크로 만든다(ORG_LINK "-" 1건).

## 구현 지침 (build용)
- 서버(server.mjs)는 바꾸지 않는다. 293건이라 필터는 브라우저에서 한다.
- 필터·판별·날짜 비교는 DOM 없는 순수 함수 ES 모듈 `public/events.js`로 분리하고(예: `isFree(row)`, `matches(row, {gu, date, freeOnly})`, `eventDates(row)`), `public/index.html`이 import한다. 테스트는 `test/events.test.mjs`(node --test, 패키지 추가 없음).
- 데이터 문자열은 innerHTML에 넣지 않는다(textContent / createElement). 현재 코드의 `innerHTML = rows.map(...)`은 교체.
- 스타일은 index.html 안 `<style>` 또는 `public/style.css` 하나. 시스템 글꼴, 포커스 링 유지, 본문 대비 4.5:1 이상.
- 날짜 비교는 문자열 `YYYY-MM-DD` 비교로 하고 `new Date()` 시간대 변환을 피한다.
